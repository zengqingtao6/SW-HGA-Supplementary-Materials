# SW-HGA Experimental Results

This repository contains the experimental results supporting the manuscript:

**SW-HGA: A Hybrid Genetic Algorithm for Traveling Salesman Problems with Profits**

## Authors

- Qingtao Zeng
- Qingwei Liu
- Xiansong Zheng
- Yiwen Zhong
- Juan Lin (corresponding author: juan.lin@fafu.edu.cn)

All authors are affiliated with Fujian Agriculture and Forestry University, Fuzhou, China.

## Repository structure

- `Experimental_Results/`: run-level records, instance summaries, component comparisons, diagnostics, diversity analyses, sensitivity analyses, and supporting ablations reported in the manuscript.
- `Code/`: intentionally contains no source code in this submission-stage release. The implementation and its provenance documentation will be added after formal publication of the article.
- `FILE_MANIFEST.csv`: relative paths, file sizes, and SHA-256 checksums for the publicly released files.

Begin with `Experimental_Results/README.md` for a detailed map between the repository contents and the experiments reported in the manuscript.
